# DevUtils Showcase ⚡️

A live interactive showcase application demonstrating the published [`@aradhya2072007/devutils-npm`](https://www.npmjs.com/package/@aradhya2072007/devutils-npm) package.

**🌐 Live Deployed Application**: [https://devutils-showcase.vercel.app](https://devutils-showcase.vercel.app)  
**📦 Published NPM Package**: [`@aradhya2072007/devutils-npm`](https://www.npmjs.com/package/@aradhya2072007/devutils-npm)  
**📂 Package Source Repository**: [github.com/aradhya2072007/npm-package-asd-project](https://github.com/aradhya2072007/npm-package-asd-project)

---

## 🌟 Overview

This application acts as a consumer project that installs and imports `@aradhya2072007/devutils-npm` directly from the official NPM registry, showcasing real-time execution of:

- **String Utilities**: `capitalize`, `slugify`, `reverseString`, `countWords`
- **Array Utilities**: `chunkArray`, `removeDuplicates`, `flattenArray`, `findMax`
- **Object Utilities**: `deepClone`, `pick`, `omit`
- **Validation Utilities**: `isValidEmail`, `isStrongPassword`, `isValidURL`
- **Number Utilities**: `clamp`, `roundTo`, `isEven`
- **Date Utilities**: `formatDate`, `timeAgo`, `isValidDate`

## 🚀 Installation & Local Development

Clone the repository:
```bash
git clone https://github.com/aradhya2072007/devutils-showcase.git
cd devutils-showcase
```

Install dependencies (installs published `@aradhya2072007/devutils-npm`):
```bash
npm install
```

Start development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
